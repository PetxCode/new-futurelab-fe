# Python Coding and AI/ML Curriculum for Secondary Schools
## Primary 4 - Senior Secondary 3

---

## CURRICULUM PHILOSOPHY

This curriculum follows a spiral learning approach where concepts are introduced early and revisited with increasing complexity. Each level builds upon previous knowledge while introducing age-appropriate new concepts.

**Core Principles:**
- Hands-on, project-based learning
- Visual and interactive tools for younger students
- Gradual transition from block-based to text-based coding
- Real-world applications and problem-solving
- Ethical AI awareness from early stages

## PRIMARY 4 (Ages 9-10)

### **FIRST TERM: Introduction to Computational Thinking**

**Learning Objectives:**
- Understand what coding and algorithms are
- Develop logical thinking and problem-solving skills
- Create simple sequences and patterns
- Introduction to basic computer operations

**Topics:**
1. What is Coding? (Week 1-2)
   - Understanding instructions and sequences
   - Daily life algorithms (making tea, getting ready for school)
   
2. Introduction to Scratch Jr/Scratch (Week 3-6)
   - Block-based programming interface
   - Creating simple animations
   - Moving sprites and changing backgrounds
   
3. Patterns and Sequences (Week 7-9)
   - Identifying patterns in nature and daily life
   - Creating pattern-based projects
   
4. Simple Games and Stories (Week 10-12)
   - Interactive storytelling
   - Basic game mechanics (movement, scoring)

**Assessment:** Simple Scratch animation project showing understanding of sequences

### **SECOND TERM: Building Interactive Projects**

**Learning Objectives:**
- Use loops and repetition in programming
- Understand events and user interaction
- Create more complex animations and games
- Introduce basic debugging skills

**Topics:**
1. Loops and Repetition (Week 1-3)
   - Forever loops, repeat loops
   - Creating patterns with loops
   
2. Events and Interactions (Week 4-6)
   - Click events, keyboard controls
   - Making interactive stories
   
3. Conditionals - If/Then (Week 7-9)
   - Simple decision making
   - Interactive quizzes
   
4. Sound and Music (Week 10-12)
   - Adding sounds to projects
   - Creating simple musical instruments

**Assessment:** Interactive game or story with user controls

### **THIRD TERM: Creative Computing**

**Learning Objectives:**
- Combine multiple programming concepts
- Work on collaborative projects
- Present and share creations
- Introduction to AI concepts (friendly robots)

**Topics:**
1. Variables - Keeping Score (Week 1-3)
   - Understanding variables as containers

3. Project Development (Week 7-10)

## IMPLEMENTATION GUIDELINES

### Teaching Methodology

**For Primary Levels (Pry 4-6):**
- 60% hands-on coding, 30% conceptual discussion, 10% assessment
- Use gamification and visual learning tools
- Short 10-15 minute focused sessions
- Pair programming and peer learning
- Immediate feedback and celebration of progress

**For Junior Secondary (JSS 1-3):**
- 50% project work, 30% theory, 20% assessment and review
- Problem-based learning approach
- Individual and group projects
- Code reviews and presentations
- Industry guest speakers

**For Senior Secondary (SSS 1-3):**
- 40% independent projects, 30% advanced theory, 20% research, 10% assessment
- Self-directed learning with mentorship
- Research-oriented approach
- Industry partnerships and internships
- Conference participation

### Assessment Framework

**Continuous Assessment (60%):**
- Weekly coding exercises (20%)
- Monthly mini-projects (20%)
- Class participation and collaboration (10%)
- Portfolio development (10%)

**Terminal Assessment (40%):**
- End of term project (25%)
- Written/practical examination (10%)
- Presentation skills (5%)

### Required Resources

**Software:**
- Scratch, Python (3.8+), Jupyter Notebooks
- VS Code or PyCharm Community Edition
- Git and GitHub accounts
- Cloud platforms (Google Colab, Repl.it)
- ML libraries: NumPy, Pandas, Matplotlib, Scikit-learn, TensorFlow/PyTorch

**Hardware:**
- Computer lab with modern computers (1:1 or 1:2 ratio)
- Internet connectivity
- Projector and interactive board
- Optional: Raspberry Pi for advanced projects

### Parent Engagement

- Monthly progress reports
- Showcase events each term
- Parent workshops on AI awareness
- Home project suggestions
- Online resources for home practice

### Teacher Professional Development

- Quarterly training on new AI developments
- Certification in Python and ML teaching
- Access to teaching resources and communities
- Collaboration with university CS departments
